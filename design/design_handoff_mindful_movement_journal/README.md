# Handoff：身心训练记录 App（Mindful Movement Journal）

## Overview
一款为「神经-身体觉知运动」实践者（瑜伽 / 普拉提 / 芭蕾 / 游泳 / 网球等）设计的**身体感知日记**。
核心思想：用「发现自己」取代「完成打卡」——不做打卡、徽章、社交、催促，只做一本能陪伴用户记录运动与身心成长的手账。
详见 `reference/core-idea.md` 与 `reference/PRD.md`。

## About the Design Files
本包内的 `.dc.html` 文件是**用 HTML 制作的高保真设计参考稿**——它演示了最终的视觉与交互意图，**不是可直接照搬进生产环境的代码**。
任务是：**在目标 App 的既有技术环境里（React Native / Flutter / SwiftUI / 原生等）重建这些设计**，沿用该环境已有的组件、导航与样式体系。
若目前还没有代码环境，请为该项目选择最合适的框架（这是一款移动 App，推荐 React Native 或 SwiftUI）再实现。

`.dc.html` 是一个自定义的轻量组件运行时（`support.js` 负责把模板 + 逻辑类渲染出来）。**不要移植这个运行时**——只需把它当作行为与视觉的说明书。`image-slot.js` 是原型里用来占位图片的拖拽组件，同样不需要移植，实现时替换为真实图片组件即可。

## Fidelity
**高保真（hifi）**。颜色、字号、间距、圆角、交互都是最终意图，请像素级还原。文案也是最终稿，可直接使用。
唯一的占位是图片（体式 GIF / 场地照 / 手账照）——原型里用 `<image-slot>` 占位，实现时接入真实资源。

## 技术基调
- **平台**：iPhone 移动 App（原型在 390×844 的手机壳内）。
- **导航**：底部 5 项 Tab（首页 / 回顾 / 中央大「＋」/ 图鉴 / 日记本），中央 ＋ 是悬浮的新增记录按钮。
- **整体气质**：森林晨光手账风。米色纸张底 + 淡格线，卡片是暖白，主强调色是柔和的森林绿。克制、留白多、无 AI slop（无重渐变、无 emoji、无彩色左边框卡片）。

## Screens / Views

### 1. 首页（Home）
- **Purpose**：轻唤醒。不放统计，只放陪伴感与「回到过去的自己」的入口。
- **Layout**：垂直滚动，自上而下：
  1. 拉丁小标（Caveat，`#9A8C6A`，如 “Sunday · July 12”）+ 中文招呼语（Serif 30px，观察式，如「午后好，慢下来一点。」）+ 副句（14px，`#8A8770`）。
  2. **上一次练习卡**（暖白卡）：标签「上一次练习」+ 手写日期；课程名（Serif 20px）；感受标签胶囊（带感受色点）+ 「距今 N 天」。点击进入记录流。
  3. **年度身体色卡缩略卡**（深绿 `#41503C`）：标题「你的身体，这一年」+ 迷你色卡网格（近 24 周 × 7 行，格子 7px）+「已记下 37 次…」。点击进入回顾页。
  4. **身体絮语卡**（暖白）：标题「身体絮语」+「翻旧页 ›」。列出最近 3 条记录：左侧手绘体式简笔（SVG 火柴人，见下）、右侧部位色点 + 日期/课程 + 一句话摘录（Serif）。点任意一条 → 跳到日记本并展开对应那条。
  5. 底部一行引导文案。
- **手绘体式简笔**：viewBox 100×140 的 SVG 火柴小人，stroke `#6B6F5B` 2px 圆角线帽，底部一条浅色地面线 `#CDBF9E`。共 4 个姿态：`fold`(前屈) / `warrior`(战士) / `bridge`(桥式) / `seated`(束角坐姿)。这是原创手绘风，实现时可保留 SVG 或换等价插画。

### 2. 记录页（Record）— 30 秒基线
- **Purpose**：一个字段即成一条。降低记录门槛。
- **Layout**（垂直滚动）：
  1. 顶部返回箭头 + 手写日期；标题「今天想留下什么？」+「第 37 次 · 一个字段，就是完整的一条」。
  2. **身体图入口**（暖白卡，横向）：左侧人体缩略图（52×78）+「身体今天哪里被唤醒了 / 已标 N 块肌肉」。点击打开 BodyMap 覆盖层。
  3. **SensationPicker**（暖白卡）：见下方交互详解。放置点后，下方出现候选感受词胶囊（可多选，上限 3）+ 一行自定义输入。
  4. **一句话**（暖白卡，textarea）。
  5. **「＋ 更多字段」**折叠区：展开出「体式（去图鉴选）」「发力感 · 老师的重点（textarea）」「时长 / 语音」「照片（image-slot）」。
  6. **CTA「记下了」**：无内容时禁用（灰 `#E7E0CD`），有任一内容时变森林绿。提交播放「合上本子」动效（见交互）。

### 3. SensationPicker（2×2 象限，签名交互之一）
- 180×180 正方形，四象限四色（见 tokens）。轴：纵轴「训练感深/浅」，横轴「消耗↔滋养」。四角标签：过载 / 饱满 / 未启 / 舒展。
- **交互**：pointer 按下/拖动在象限内放置一个圆点（26px，森林绿 + 3px 纸色描边 + 阴影）。坐标归一化到 [-1,1]。
- 点落在哪个象限，就切换出对应的一组候选词：饱满→[充实,饱满,清晰,激活,突破,有力]；舒展→[放松,舒展,通透,宁静,轻盈,恢复]；过载→[累,酸,紧,颤,闷,勉强]；未启→[无感,空,麻木,走神,浮,隔]。

### 4. BodyMap（身体图，覆盖层）
- 从记录页底部弹出（圆角顶 sheet，深色背景遮罩）。
- 顶部「前视 / 后视」分段切换。中央一个由 CSS 方块拼出的人体（头/躯干/双臂/双腿），上面叠 14（前）/ 12（后）块可点肌肉热区（按百分比定位）。
- **交互**：点一块肌肉 → 从底部滑入一个 sheet（`sxSheet` 动效），列出感受标签「酸/紧/温/涨/无感」，点一个即给该肌肉着色（用感受色）。可标多块。「完成」关闭。
- 肌肉清单（id/名称/部位）见源码 `FRONT_MUSCLES` / `BACK_MUSCLES`。⚠ 这批肌群与象限词是 PRD 里的团队假设，上线前建议做 5 人访谈校准。

### 5. 图鉴（Pose Picker）
顶部「按体式 / 按肌肉群」分段切换。
- **按体式**（反向找体式）：搜索框 + 体式家族横向 tab（全部/前屈/后弯/扭转/侧弯/平衡/倒立/中正）+ 两列体式卡（图片占位 + 家族角标 + 中英名 + 主要肌群 +「看它练哪里 ›」）+ 底部「说不出名字？用自己的话记下来」。
- **按肌肉群**：肌群横向 tab（核心/臀/髋/腿后侧/大腿前侧/肩背）→ 选中后：人体图高亮该肌群（自动切前/后视）+ 一句作用描述 + 部位标签 +「练到它的体式」两列卡（每张标注「拉伸」或「主动/协同」发力角色）。数据见源码 `MUSCLE_GROUPS`。

### 6. 体式详情（Pose Detail）
- 顶部大图（体式 GIF 占位，270px，底部渐隐进纸色）+ 返回 + 家族角标。
- 中英名。**主要激活肌群**卡（左侧人体高亮相关肌群 + 右侧肌群胶囊）。**发力感线索**卡（绿点）。**常见代偿点**卡（粉点）。**常见感受词**卡（点一个直接进记录流）。**我的发力感笔记**卡（深绿，Serif 引用体）。

### 7. 回顾页（Review，签名页）
垂直滚动，顺序：
1. 标题「这一年，你的身体」+ 观察式副句。
2. **年度身体色卡**（暖白卡）：53 列 × 7 行网格（格子 5px），每格一天，按当天状态着色（正向绿梯度 / 负向赭梯度 / 空色）。**点任意格** → 卡片底部展开那天的手写日期 + 一句话（`sxPop` 动效）。底部图例：滋养→充分梯度条 + 过载色块。
3. **「过去一周，你的身体最像什么？」**（深绿卡，观察式小结）。
4. **身体在慢慢变化**（暖白卡）：4 条极简 SVG 折线趋势（力量/柔韧度/体能/觉察），右侧文字趋势标注。
5. **哪个部位在反复提醒你**（暖白卡）：横条（髋/核心/肩/大腿后侧，出现次数）。
6. **这一年，你陪自己练了多少**（暖白卡）：「运动类型 / 部位」分段切换；两个概览数字（次练习 / 累计时长）；下方横条（按类型：普拉提/瑜伽/芭蕾/游泳；按部位：核心/髋/肩背/腿），每条显示 次数 + 时长。

### 8. 日记本（Diary）
- 标题「日记本」+ 观察式副句 +「全部 · 37 篇」。
- **「时间线 / 按训练类型」**分段切换：时间线按月分组（七月/六月…），按训练类型按运动分组（普拉提/瑜伽/芭蕾/游泳）。
- 每条卡：手绘体式简笔 + 手写日期 + 课程类型 + 感受色标签 + 一句话摘录（Serif）。**点卡片展开**：发力感笔记 + 时长 + 身体标注处数（`sxFadeUp` 动效）。

## Interactions & Behavior
- **导航**：Tab 切换 home/review/poses/diary；中央 ＋ 与各处「新增记录」入口都进记录流（会重置记录草稿 state）。BodyMap 是记录页上的覆盖层，非独立路由。
- **象限放点**：pointerdown + pointermove 捕获，归一化坐标 [-1,1]，实时更新圆点位置与候选词。
- **候选词多选**：上限 3，选中反色（绿底浅字）。
- **肌肉标注**：点肌肉 → 底部 sheet 选感受 → 给肌肉着色，可多块。
- **提交动效**（`sxBookClose`，约 1.5s）：全屏遮罩 + 合上本子图标 +「记下了。合上本子，明天见。」，结束后回首页并清空草稿。
- **年度色卡选日 / 日记卡展开**：局部展开，带 `sxPop` / `sxFadeUp`。
- **动效关键帧**（见源码 `<helmet><style>`）：`sxFadeUp`（进场上浮）、`sxPop`（弹入）、`sxSheet`（底部滑入）、`sxBookClose`（合本）。缓动多用 `cubic-bezier(.2,.8,.2,1)` 或 `ease`。

## State Management
主要 state（单组件持有，实现时按你的状态方案拆分）：
- `screen`：当前页（home/record/poses/poseDetail/review/diary）。
- 记录草稿：`coord`（象限坐标）、`words`（候选感受词）、`note`、`annotations`（肌肉id→感受）、`pose`、`showMore`、`view`（前/后视）、`bodyOpen`、`pending`（正在标注的肌肉）。
- 图鉴：`poseMode`（pose/muscle）、`family`、`muscle`。
- 回顾：`statMode`（kind/part）、`selectedDay`。
- 日记：`diaryView`（all/type）、`diaryOpen`（展开的条目 id）。
- `closing`：提交动效开关。
所有列表数据（POSES / MUSCLE_GROUPS / 肌肉清单 / 年度格子 / 日记条目）在原型里是本地示例数据，实现时接后端。年度色卡用了一个确定性伪随机填充做演示。
