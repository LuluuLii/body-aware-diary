# 小红书用户调研

> 方法：puppeteer 抓取 3 组关键词共 30 条搜索结果 + 9 篇正文/评论详情。
> 时间：2026-07-05
> 关键词：`普拉提课后感` / `瑜伽笔记` / `普拉提日记`
> 原始 JSON：同目录 `xhs-*.json`
> **目的**：验证或修正 [`product-benchmark.md`](./product-benchmark.md) 里基于海外产品得出的方向。

---

## TL;DR — 6 条核心发现

1. **情感/疗愈语言是这类用户的默认表达方式**。用户主动说的不是"我瘦了 X 斤"，而是"内心变得平静"、"掌控感"、"第三视角"、"和自己和解"。**这直接印证我们的定位**。
2. **"我不知道自己在练什么" 是最痛的痛点**，且强度远超预期——练半年、上 200 节课后仍然"离开老师就一片空白"。**是我们的 P0 机会**。
3. **老师之间说法矛盾** 是次痛点。用户需要一个**中立的、跟自己身体反馈走的记录空间**，不是又一个教练意见的搬运工。
4. **现有记录行为几乎全靠手动**：手写笔记、XHS 帖子、教培课本、Vlog。**没有专门工具**——这不是"红海挤进去"，是空白。
5. **体式分类学是明确的信息需求**——按方位（前屈/后弯/扭转/侧弯/平衡/倒立/中正）分类的科普内容点赞不低。可直接抄进我们的"个人身体图鉴"。
6. **警觉信号**：练习不总是好的。有"开肩开髋身体反而越来越差"、"练完僵硬"、"两个体系打架"这类反面帖。**回顾功能要能承载负向感受，不能只做鼓励式呈现**。

## 主题一：情感疗愈是主流叙事

在"普拉提课后感"关键词下，**高赞帖几乎全部是情感向而非动作向**。用户自发使用的词汇：

- "内心变得平静"
- "突破的那几秒的满足感"
- "掌握身体的掌控感"
- "出现了第三视角，链接感好棒"
- "在普拉提床上才发现自己内心特别脆弱"（3836 赞）
- "把注意力转向：我有没有在好好呼吸"
- "慢慢和自己和解的方式"
- "改变你对生活节奏的感知方式"
- "一节瑜伽课，比任何社交局都锋利"（949 赞）

**对我们的意义**：
- SensationPicker 里的感受词汇不能只是身体的（酸、紧、松），必须**涵盖身心链接的词**（平静、突破、脆弱、掌控、和解、边界）
- 回顾页的摘要文案调性应该匹配这种叙事——"这周你的身体在告诉你什么？" 而不是 "本周训练报告"
- 空态文案可以放这种用户原声句子作为微文案启发

---

## 主题二：核心痛点——"我不知道自己在练什么"

这是本次调研**最强的信号**。代表帖子：

**"练了半年普拉提才发现：我根本没在学习"**（424 赞）
- 作者练半年后意识到：**离开老师就完全空白**——不知道每个动作练哪里、顺序怎么排、今天该做什么
- 评论区高度共鸣：
  - "上了两百多节课，自己在家啥也不会，自己一练就代偿"
  - "醍醐灌顶，我也是这样。一个执行力很好的行动者。但不是学习者"
  - "从今年开始改变的。开始和老师设定目标，每 5-8 节完成一个部位。专注腹部，髋部，现在到背部了。进步超快"

**"普拉提真的太难了 - 来自新手的吐槽"**：
- "呼吸也好难，练动作也难，呼吸加动作更难"
- **不同老师说法各有不同**——用户很困惑
- 想改善"塌臀和减腹"，但方法不确定，一节私教课贵，练错怕亏

**对我们的意义（这是 P0 功能设计的核心）**：
- 记录页的"体式"字段虽然非必选，但**必须为用户"记不住名字"这个情况准备兜底**：
  - 用"部位 + 体式家族" 反向找体式（例如"我练了髋" + "扭转类" → 系统给出候选体式）
  - 支持"临时命名"（用户可以用自己的话记 "老师说的那个扭转"），后续再补正式名
  - 图片选（GIF 卡片墙）比文字选更符合新手认知
- 回顾页应能呈现用户**"我练了什么部位、什么模式"** 的累计视图（而不是逐日流水），帮用户看到自己无意识形成的偏好和盲区
- "每 5-8 节完成一个部位"的用户实践，暗示可以做一个**"焦点部位"**功能——用户自己设定当前关注部位（不是我们推荐），在回顾里高亮

## 主题三：老师体系冲突 → 用户需要中立记录空间

代表帖 **"😂 感觉两个体系在打架"**（254 赞）：
- 用户同时练普拉提 + 撸铁，感觉整个人僵了
- 拉伸教练说需要更多拉伸；普拉提教练强调另一套；撸铁教练又一套
- 评论区多派老师意见分裂

**对我们的意义**：
- 我们的"个人身体图鉴"里的动作/知识**不要预设唯一权威**。可以为同一体式提供多流派备注（"某流派强调 X，另一流派强调 Y"）
- 更重要的是：**用户自己的身体反馈才是主线**。回顾页的洞察应指向"你的身体在这个动作里反复出现 Y 感受"，而不是"某老师说应该 X"
- 这也是我们和 Alo Moves / Down Dog 的最大差异化——他们是"老师给你答案"，我们是"你给自己答案"

## 主题四：现有记录行为几乎全靠手动

调研中出现的记录方式：
- **手写笔记本**（"发现去年的瑜伽笔记"）
- **XHS 帖子本身**（大量帖子就是把课后感发到小红书当日记）
- **教培课笔记**（"这是新鲜出炉整理的昨天瑜伽教培课笔记"）
- **Vlog** 视频记录
- 私教课后跟教练口头复盘

**没有**：
- 专门的普拉提/瑜伽记录 App（Keep 等都是撸铁记账逻辑）
- 结构化的身体感受记录工具
- 长期回顾工具

**对我们的意义**：
- 这是**明确的空白市场**。既不是与 Keep 竞争，也不是与 Alo Moves 竞争
- 用户当前把 XHS 当日记的行为暴露了**分享冲动 vs 私密觉察**的矛盾——她们发帖有社交/被看见的需求。**但**我们坚持不做社交（前面已定），因为社交会异化记录动机。可以考虑**导出精美图卡**功能，让用户把某条记录变成可自发分享到 XHS 的图，社交发生在站外，站内保持纯粹
- 教培学员群体（想成为老师的学员）是隐性大用户——她们记录动机极强，且愿意付费。**未来可探索是否为教培学员做专属模式**

## 主题五：体式分类学是明确的知识需求

代表帖 **"瑜伽体式那么多，其实就这 7 大类"**（79 赞）：
- 按方位/方向：前屈 / 后弯 / 扭转 / 侧弯 / 平衡 / 倒立 / 中正
- 每类给出体式示例 + 主要作用（拉伸、按摩内脏、增强背部力量 etc.）

评论区还有大量用户主动分享细节知识：
- "上课前踩泡沫轴激活足底"
- "松解背部因为肩胛骨上移"
- "松解大腿前侧因为跟腹肌相连"
- "髂腰肌没有能力时大腿前侧容易过度发力"

**对我们的意义**：
- **"个人身体图鉴"的体式分类可以直接采用 7 大类**：前屈 / 后弯 / 扭转 / 侧弯 / 平衡 / 倒立 / 中正。这是社区已经消化过的分类，用户看得懂
- 体式详情页可以包含：主要肌群 / 常见代偿点 / 常见感受词。不做"教程"，做"识别参考"
- 用户在评论区自发贡献的知识很有价值，未来可以做**"用户贡献动作卡"**（用户导入的动作可以被自己复用，做得好可以私域分享给朋友；不做公域社交）

## 主题六：练习节奏与"看见变化"

高赞标题模式：
- **"每周两三次普拉提，一年 144 次你就会发现"**（208 赞）
- **"瑜伽 50 次后"**（16 赞）
- **"练了半年普拉提"**（424 赞）
- **"上了 70 节课之后 出现了第三视角"**（评论）
- **"上了两百多节课"**（评论）

用户在**用课时数量作为时间维度**追踪自己的变化，而不是天数或周数。

**对我们的意义**：
- 回顾页的时间轴维度可以做双轨：**日历时间**（本周/本月）+ **课时时间**（第 N 节课）
- "第 50 节课"、"第 100 节课"这类里程碑是有价值的（**不是打卡数字，是变化维度**）——可以做"里程碑回顾"，弹出一次"回望前 50 节"的整合视图
- **注意区别**：不做 streak（连续天数），做累积课时（累计次数）。前者是打卡，后者是里程

## 主题七：警觉信号——练习不总是好的

代表帖：
- **"开肩开髋，身体反而越来越差"**（48 赞）
- **"练完普拉提会困是气虚吗？"**（237 赞）
- **"感觉两个体系在打架"**（254 赞）—— 撸铁后普拉提感觉自己僵了

**警觉信号里没有的一条**（重要修正）："30 岁以后才明白，原来练瑜伽真的没什么用"（467 赞）**标题看似负面，正文其实是强验证**——用户明确说瑜伽对身材"没用"，但被她当成"放松疗愈自己的方式"，"每日重复重复的基础练习让身体舒畅心情舒畅"、"30+ 以后爱自己真的要加上放松身心这一项"。这类"钩子标题反证内心"的表达模式非常典型，应作为 [主题一] 情感疗愈叙事的进一步佐证。

**对我们的意义（重要）**：
- 回顾页**不能只做"你进步了"的正面呈现**。要能承载"你的睡眠在这个练习模式下变差了"、"你的髋部感受下降了"这类反面模式
- 空态/文案要**避免运动崇拜**："保持觉察"比"坚持练习"更符合我们的调性
- 这个信号也印证 Bearable 的 correlation 面板做法——把因果解读还给用户，我们只呈现相关，不背书任何断言

## 与 product-benchmark.md 的方向对齐

| 之前的假设 | XHS 验证结果 | 是否需要调整 |
|---|---|---|
| 主场景 = 课后 5 分钟快速记录 | ✅ 验证。用户当前多在课后立刻发 XHS，说明有强录入冲动 | 不变 |
| 动作/体式非必选 | ✅ 强验证。"记不住名字"是普遍问题 | 不变，但增加"部位反向找体式"能力 |
| 不做 AI 对话 | ⚠️ 需要注意：Yitta 那篇高赞帖恰恰是用户跟 AI 对话获得启发。**不代表我们要做**，但说明用户会通过其他渠道满足这类需求 | 保持不做；未来可评估"引导式提问"是不是够 |
| 不做 streak | ✅ 验证。用户自发用课时（第 N 节课）而非天数追踪 | 不变；改做"累积课时里程"（非打卡强化） |
| 观察式文案 | ✅ 强验证。用户自身语言就是内省式的 | 不变，可以从帖子里直接借用户原话丰富文案库 |
| 补充"睡前扫描 / 晨起感受" | ⚠️ 数据未直接验证。这两个入口用户没有自发讨论 | 建议先做核心记录，睡前/晨起入口 P2 再上；上线后小流量测试 |

## 新增建议

以下 3 条来自 XHS 数据，`product-benchmark.md` 未涵盖，建议纳入 Sprint 规划：

**新增 A（P0）**："部位反向找体式" 的选择流
- 场景：用户课后想记体式但忘了名字
- 流程：点"部位"（BodyMap 或简易列表） → 选"体式家族"（7 大类）→ 系统显示候选体式卡片墙（图/动图）→ 选中或用自定义名保存
- 覆盖 XHS 里最强的痛点（"我不知道自己在练什么"）

**新增 B（P1）**：焦点部位 / 累积课时
- 用户可自设当前关注部位（1-3 个）
- 回顾页高亮该部位的累积次数 + 感受变化
- 满足"每 5-8 节完成一个部位"的用户自发实践

**新增 C（P1）**：图卡导出
- 记录/回顾可导出为高质量图片，用户可选择自发分享到 XHS
- 站内不社交，站外自由
- 解决"我想分享 vs 我想私密"的矛盾
