# 产品核心思想 · Core Idea

> 这是所有功能决策的锚点。任何 PR、设计稿、需求变动都应能追溯到这里。
> 版本：v1 · 2026-07

---

## 一句话

**为瑜伽、普拉提、游泳、网球、芭蕾这类"神经-身体觉知运动"的实践者，做一本身体感知日记——让每次练习变成一次和身体的对话，用"发现自己"取代"完成打卡"。**

> **什么是"神经-身体觉知运动"**：这类运动的共通训练机理是——**神经系统对身体（尤其小肌群）的精细感知与控制**（对应生理学概念 proprioception / motor control）。它们和撸铁的核心差异不在动作类型，在训练主体：撸铁训练肌肉的**大小/力量**，这类运动训练神经与肌肉之间的**对话质量**。这也是为什么用"组数×重量"记录它们是错的坐标系——没法用磅数量化。
> 瑜伽、普拉提、芭蕾等运动，体式和组合比较多，新手难以直接记录训练到的动作和肌肉。
---

## 目标用户

**主用户画像**：
- 城市中，有稳定练习节奏（每周 1-3 次）的瑜伽 / 普拉提 / 游泳 / 网球 / 芭蕾 / 舞蹈实践者
- 25-40 岁，以女性为主但不限
- 至少 3 个月练习积累
- 会主动写手账、发 XHS 课后感、拍课后自拍
- 对 Keep 式的"动作 × 组数"记录**已经放弃或从未接受**

**代表原声**（均来自本项目 XHS 调研原始帖）：
- "练了 200 节课，自己在家啥也不会"
- "掌握身体的掌控感"
- "内心变得平静"
- "我今天想激活髋外展肌群"（用户第一次给自己发指令）
- "30 岁以后，爱自己真的要加上放松身心这一项"

**不是给谁的**：
- 追求"我今天举了多少公斤"的力量训练者
- 追求"打卡拿徽章"的健身新手
- 追求"AI 教练带练"的懒人
- 追求社交曝光的健身博主

---

## 要解决的核心问题

主流健身 App 用 "动作 × 组数 × 重量" 记账，对这批用户是**错误的坐标系**。她们练的不是"我搬了什么"，而是**"我能否精细地感知并控制我的身体"**。

4 个未被满足的诉求：

1. **"我不知道自己练了什么"**——练半年、上 200 节课，离开老师就一片空白
2. **"我记不住动作名"**——新手连体式名都说不出，别谈复盘
3. **"我想知道刚才是哪块肌肉在发力"**——目前没有轻量工具帮她们把 **动作 → 主要激活肌群 → 发力感线索 → 常见代偿** 这条链串起来
4. **"我想留下点什么，但没有合适的空间"**——手账散乱、通用日记 App 又太重

---

## 我们做什么

**一件事**：给她们一个私密、克制、有仪式感的空间，让身体感受被记录、被回顾、被看见。

这个空间由三个核心动作构成：

### 1. 课后 5 分钟快速记录（低摩擦 · 高仪式感）
- 默认路径 30 秒内可完成：**部位 + 感受 + 可选一句话**
- 可选深化：
  - 上传照片（练习场景、镜子自拍、日出、场地）
  - 语音留言
  - 手写笔记扫描
  - 体式标注
- **仪式感 ≠ 复杂**——是每次交互的质感（触感反馈、留白、色卡、动效），不是字段数
- **默认极简 + 可选深化**，从不为了完成度而逼字段

### 2. 身体图鉴的反向查询（重点特性 ⭐）
- **反向找体式**：从"我练了哪个部位/哪种体式家族" → 系统给出候选体式卡片墙 → 选中入记录
- **体式详情四段固定结构**：
  1. **主要激活肌群**（图 + 简短文字）
  2. **发力感线索**（例："想象骨盆前倾时坐骨往下扎"）
  3. **常见代偿点**（例："下背部容易过度用力"）
  4. **常见感受词**（用户可直接从这里选进当天的记录）
- **这不是教程，是识别参考**——用户来"认出"她练过的，不是"被教怎么练"
- 从任意记录反向跳转（点击日记里的"下犬式" → 看到你在下犬式的历史感受轨迹）
- 内容分类采用 XHS 社区已消化的**瑜伽 7 大类**：前屈 / 后弯 / 扭转 / 侧弯 / 平衡 / 倒立 / 中正
- 用户可自定义添加个人体式（图鉴的第二层）

### 3. 回顾时的"看见"
- 用**年度色卡**（每天一格）、**里程课时**（第 N 节课）、**部位模式**（哪个部位反复出现）呈现"过去几周你的身体在告诉你什么"
- 承载**正负两向感受**——不能只做鼓励式；用户会有"开肩开髋反而更差"这类经历，回顾必须能坦然显示
- 引导式回顾：
  - "过去一周你的身体最像什么？"
  - "哪个部位在提醒你？"
  - "下周你想给自己一个什么练习？"

## 我们的差异化

不是"更好的 Keep"，也不是"更瑜伽的 Strong"，也不是"更专业的 Daylio"。

| 对比 | 差异点 |
|---|---|
| vs Keep / Strong / Hevy | 不用组数计数身体，用感受 |
| vs Alo Moves / Down Dog | 不做老师权威，做用户身体的镜像 |
| vs Daylio / Reflectly | 深度在**身体维度**（部位/感受/体式），不是抽象情绪 |
| vs Bearable | 不是慢病追踪，是觉察日记；语气温柔不密集 |
| vs XHS 手账 / 朋友圈 | 私密、结构化、可长期回顾 |
| vs Notion / Day One | 有身体维度的原生数据结构，不需要用户自己搭 |

---

## 为什么是现在

- 瑜伽/普拉提在国内从"新鲜"进入"日常"——XHS 上"练了 X 节课后我发现了什么"能有几百上千赞的共鸣量，说明基础用户规模化
- 主流健身 App 都在向撸铁 + 饮食追踪卷；"神经-身体觉知运动 + 日记" 这条赛道空白
- 用户已经在自发做记录（手账、XHS、通用日记 App），没有对应工具承接
- 目标人群（25-40 岁女性 + 30 岁+ 心态转向"疗愈自己")与"手账文化"高度重叠，产品调性和市场氛围契合

---

## 成功长什么样

**不是**：DAU 破百万、GMV 千万。

**是**：一位用户使用一年后，能翻开她的历史说 "**这就是我今年的身体**"。看到她自己都没意识到的模式；翻到某个久违的感受词，眼眶湿了一下。

**那就是这个产品做到了它该做的事。**
